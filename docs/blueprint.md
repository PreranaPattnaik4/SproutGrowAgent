# **App Name**: SproutGrowAgent

## Core Features:

- Image-Based Disease Diagnosis: Upload images of plant leaves to receive diagnoses of potential diseases, using an AI model to analyze the images.
- Voice Query Assistant: Farmers can ask questions and receive advice via voice interaction, using speech-to-text and text-to-speech technologies. An LLM tool decides how, and whether, to integrate other forms of information (such as information about local schemes, weather and market prices) into the response.
- Text Chat Interface: A traditional text-based chat for farmers to interact with the AI assistant, providing another mode of communication. The tool can use the history of the text chat to respond better.
- Location-Based Information: Provide market prices, weather forecast, and eligible government schemes based on the farmer's current location.
- Multilingual Support: Offer support in multiple languages to cater to diverse user base. UI must be adaptable.
- Fixed Sidebar Navigation: Fixed left-hand sidebar for main navigation (Home, Image, Voice, Text, Location, Language).
- Chatbot Popup: A global, fixed chatbot button that opens a modal/popup containing the text chat interface, providing easy access to the AI assistant from any page.

## Style Guidelines:

- Primary color: Forest Green (#386641) evoking nature and growth.
- Background color: Pale Green (#F7F9F4) for a calm and soothing ambiance.
- Accent color: Yellow-Orange (#ECAA47) provides contrast and highlights important elements.
- Headline font: 'Belleza' (sans-serif) brings personality and a modern look, suitable for headlines. Body font: 'Alegreya' (serif) for a balance of elegance and readability, suited for the paragraph blocks.
- Code font: 'Source Code Pro' for displaying API endpoints, if needed.
- Use minimalist icons for easy navigation and visual appeal.
- Implement a clean and intuitive layout with large, tappable buttons suitable for older users.
- Subtle animations and transitions to enhance user experience, such as a shining effect on the Chatbot button.
