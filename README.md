# SproutGrow Agent

This is a Next.js application built with Firebase Studio, designed to be an AI Farming Companion.

## Getting Started

To get started with development:

1.  **Install dependencies:**
    ```bash
    npm install
    ```

2.  **Run the development server:**
    ```bash
    npm run dev
    ```

Open [http://localhost:9002](http://localhost:9002) with your browser to see the result.

## Key Features

The application includes several AI-powered features to assist farmers:

-   **Image Diagnosis:** Upload a photo of a plant to diagnose diseases.
-   **AI Assistant:** A multi-modal assistant for general farming queries.
-   **Crop Planner:** Get personalized crop plans based on soil, location, and date.
-   **Location-Based Info:** Provides mock data for weather, market prices, and government schemes.

For a full breakdown of all features and the project architecture, please see [REPORT.md](./REPORT.md).
